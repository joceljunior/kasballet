# KasBallet - Documentação

## Visão Geral

Sistema de gestão para escola de dança desenvolvido com Vue 3, Tailwind CSS e Back4App (Parse SDK).

## Estrutura do Projeto

- `src/repositories/` - Camada de acesso a dados (abstração BaaS)
- `src/services/` - Camada de serviços (lógica de negócio)
- `src/stores/` - Gerenciamento de estado (Pinia)
- `src/views/` - Páginas da aplicação
- `src/components/` - Componentes reutilizáveis
